# 업무 자동화 포트폴리오 (크몽·해외 프리랜서용)

크몽 등에서 "직접 눌러보는 데모"로 신뢰를 주기 위한 포트폴리오 사이트. 서버 없이 HTML 파일만으로 동작한다(무료 호스팅 가능).

## 폴더 구조
| 파일 | 역할 |
| --- | --- |
| `config.js` | **브랜드명·문구·가격·운영비·사후관리·크몽 링크·FAQ** — 보통 이것만 고치면 됨 |
| `index.html` | 메인(서비스 소개, 데모 링크, 진행 방식, FAQ) |
| `demo-excel.html` | 주문 엑셀 → 택배 송장 양식 변환 + 상품별 집계 (실제 파일 처리, 브라우저 안에서만) |
| `demo-kiosk.html` | 무인매장 QR 결제 → 기기 ON/OFF + 사장님 현황판 (가짜 결제, 60배속 시계) |
| `demo-dashboard.html` | 경쟁사 가격 모니터링 대시보드 (가상 샘플 데이터 + 수집 시뮬레이션) |
| `assets/style.css`, `assets/common.js` | 공통 디자인·도우미 함수 |

## 실행(내 PC에서 보기)
```
python -m http.server 8090
```
→ 브라우저에서 http://localhost:8090

## 공개하기(무료)
GitHub Pages 또는 Netlify Drop(폴더를 끌어다 놓기)에 올리면 링크가 생긴다. 그 링크를 크몽 서비스 설명·포트폴리오에 넣는다.

## 확장 방법(새 데모 추가)
1. `demo-xxx.html` 을 기존 데모 하나 복사해서 만든다(헤더/푸터/스크립트 로드 구조 유지).
2. `config.js` 의 `services` 에 항목 하나 추가하고 `demo: "demo-xxx.html"` 로 연결 → 메인에 자동 표시.

## 주의
- 데모 데이터(이름·주소·쇼핑몰)는 모두 가상. 실명·실제 고객 데이터를 넣지 않는다.
- 실명 대신 브랜드명으로 운영한다.
